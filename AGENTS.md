## Graphify

This project has a knowledge graph in `graphify-out/`.

- For codebase questions, first run `graphify query "<question>"` when `graphify-out/graph.json` exists. Use `graphify path` for relationships and `graphify explain` for a focused concept.
- If `graphify-out/wiki/index.md` exists, use it for broad navigation.
- Read `graphify-out/GRAPH_REPORT.md` for broad architecture reviews or when graph queries are insufficient.
- After code changes, run `graphify update .` to refresh the graph.
